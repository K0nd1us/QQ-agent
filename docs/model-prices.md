## 渠道与自定义价格

上表是**内置**价格，供「用内置官方价格表估算」开关打开时使用（此时只读）。

同一个模型 id 走不同**渠道**（A6API / OpenRouter / 本地中转…）视为不同商品，
按「渠道：模型 id」分别统计与设定价格。

自定义价支持两级：可为「渠道：模型 id」设渠道专属价，未设则回落到该模型的通用价。
开关关闭后才能编辑；修改只写入你自己的配置，**不会改动本表**。
