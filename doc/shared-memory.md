# 按 QQ 号共享、持续更新的群友印象

同一 QQ 在不同群与私聊使用 `data/memory/members/<QQ>.json` 中的同一份印象。会话目录的 `_members.json` 只维护关联。旧印象保留来源会话，提示词标明群内关系只适用于对应会话。名字不再用于猜测或合并身份；没有确认 QQ 号的旧条目保留在原会话。

默认累计 20 条该成员尚未处理的有效文字发言，且距离该 QQ 上次更新超过 6 小时，才在后台用一次模型请求结合旧印象和新发言更新。设置中的“印象更新”可以关闭自动更新、调整条数与冷却，并选择专用模型。静默消息也会累计，冷却结束和重启后会检查尚未处理的发言；因此后台更新可能增加模型用量。每次最多分析 40 条、更新 3 人，每人默认最多 5 条。手动更新可跳过条数与冷却。

采样只读取允许的会话，排除自己、拍一拍、撤回、空消息和屏蔽成员。跨会话按 QQ 号互斥；模型请求期间管理员或工具修改印象时，旧快照不能覆盖新编辑。无效结果和失败保留印象及游标，至少等待一分钟后重试。有效空数组也记录处理进度。

首次读取会迁移旧的按群成员文件和旧单文件，按确认的 QQ 号合并、去除完全重复的印象。源文件在修改共享文件之前备份到 `data/memory/backups/`；已有不同备份不会被覆盖。备份失败、损坏文件或 QQ 号不一致会报错并保留源文件，修复问题后可重试。

升级前应退出程序并备份完整 `data/memory/`。回退旧版代码时恢复迁移前备份：旧版不认识共享目录，直接使用迁移后的数据会看不到原记忆。自动生成的备份用于找回迁移源文件，不替代整个记忆目录的升级前备份。

编辑和删除某 QQ 的印象会在所有群与私聊生效。删除会话记忆只移除关联，共享印象保留；清空成员印象保留已处理游标，避免立即重复分析旧聊天。
