多号接入说明（第一次用建议看一遍）

一个 QQ 号 = 一套 OneBot 地址。每个号必须有自己的 WS/HTTP 端口，不能两个号填同一组地址，否则会互相抢事件、重复回复。账号中心检测到重复会直接标红。

内置协议端。安装版内置的 SnowLuma 随 1 号账号启动；其它号需要在协议端里单独开一套端口（或使用另一个协议端实例），然后在对应账号的「打开控制台 → 设置 → OneBot」里填写。

数据边界。记忆、聊天存档、会话、用量、模型/搜索 Key、白名单、人设、提醒、技能与插件开关、日志都按号独立；skills/ 与 plugins/ 的代码全机器共用，升级/安装一次即可。

启停。每个号可以单独启动、停止、暂停；关闭程序时全部一起退出，下次打开按各自的「启用」状态自动恢复。

新建账号

会从 1 号账号复制设置模板（人设、聊天策略、工具、技能开关、界面偏好），并自动清空模型 Key、协议端令牌、白名单、屏蔽名单与聊天数据。

名称只用于账号中心显示，可以随时改。
